# CSE-FEDRAMP-AT-NO-TRAINING-RECORDS-004

**No Training Records**

## Signal Overview

| Field           | Value                                     |
|-----------------|-------------------------------------------|
| Identifier      | `CSE-FEDRAMP-AT-NO-TRAINING-RECORDS-004` |
| Domain          | FEDRAMP                                   |
| Category        | AT                                        |
| Status          | Active                                    |
| Introduced In   | 1.0.0                                     |

## Description

Individual training records are not documented, monitored, or retained for the required period.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Awareness and Training (AT)
**Control:** AT-4
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Document and monitor information security and privacy training activities, including security and privacy awareness training and specific role-based security and privacy training; and retain individual training records for the period specified by the organization."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing training databases, incomplete training completion records, lack of training activity monitoring, absence of retention policies, and no audit trail of training compliance.
