# CSE-FEDRAMP-PE-NO-ENVIRONMENTAL-006

**No Fire Protection**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-FEDRAMP-PE-NO-ENVIRONMENTAL-006` |
| Domain          | FEDRAMP                                  |
| Category        | PE                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Fire protection and suppression capabilities are not employed and maintained to protect facilities containing information systems.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Physical and Environmental Protection (PE)
**Control:** PE-13
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Employ and maintain fire detection and suppression systems that are supported by an independent energy source."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing fire detection systems (smoke detectors, heat sensors), lack of fire suppression systems (sprinklers, gas-based suppression), absence of independent energy/power sources for fire protection, inadequate maintenance records, missing inspection reports, and non-compliance with local fire codes.
