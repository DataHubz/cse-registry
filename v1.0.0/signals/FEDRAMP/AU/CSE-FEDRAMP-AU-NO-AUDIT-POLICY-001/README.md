# CSE-FEDRAMP-AU-NO-AUDIT-POLICY-001

**No Audit Policy**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-FEDRAMP-AU-NO-AUDIT-POLICY-001` |
| Domain          | FEDRAMP                                  |
| Category        | AU                                       |
| Status          | Active                                   |

## Description

Audit and accountability policy and procedures are not established.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Audit and Accountability (AU)
**Control:** AU-1
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Develop, document, and disseminate an audit and accountability policy... and procedures."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing audit policy documentation, undefined auditable events, and absence of audit procedures.
