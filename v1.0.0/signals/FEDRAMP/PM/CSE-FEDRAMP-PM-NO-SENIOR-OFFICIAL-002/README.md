# CSE-FEDRAMP-PM-NO-SENIOR-OFFICIAL-002

**No Information Security Program Leadership**

## Signal Overview

| Field           | Value                                          |
|-----------------|------------------------------------------------|
| Identifier      | `CSE-FEDRAMP-PM-NO-SENIOR-OFFICIAL-002`        |
| Domain          | FEDRAMP                                        |
| Category        | PM                                             |
| Status          | Active                                         |
| Introduced In   | 1.0.0                                          |

## Description

Senior information security officer or equivalent leadership role is not appointed to manage the organization's information security program.

This signal indicates that the organization may lack designated senior leadership with the authority and responsibility to oversee and manage the information security program across the organization.

## Applicability

This signal applies to:

- Cloud Service Providers (CSPs) pursuing FedRAMP authorization
- Federal agencies managing information systems
- Third Party Assessment Organizations (3PAOs) conducting assessments
- Federal information systems processing, storing, or transmitting federal data
- Organizations supporting federal cloud services

## FedRAMP Context (Informative)

### Control Family
Program Management (PM)

### Control
PM-2: Information Security Program Leadership Role

### Baseline
Low, Moderate, High

### NIST SP 800-53 Rev. 5
The organization:
- Appoints a senior agency information security officer with the mission and resources to coordinate, develop, implement, and maintain an organization-wide information security program
- Ensures that the senior agency information security officer:
  - Possesses the professional qualifications, including training and experience, required to administer the information security program functions
  - Has information security duties as a primary responsibility
  - Heads an office with the mission and resources to assist the organization in achieving more secure information and systems

These references are informative and do not constitute compliance guidance.

## Notes

Detection of this signal typically involves:

- Review of organizational charts and leadership appointments
- Verification of designated senior information security officer or Chief Information Security Officer (CISO)
- Assessment of officer's professional qualifications, training, and experience
- Examination of officer's primary duties and responsibilities
- Review of office structure, mission statement, and allocated resources
- Verification of officer's authority and reporting relationships
- Assessment of officer's access to senior leadership and decision-making processes
- Evaluation of officer's span of control across organizational security functions

The presence of this signal indicates a condition that warrants review in the context of FedRAMP program management requirements.
