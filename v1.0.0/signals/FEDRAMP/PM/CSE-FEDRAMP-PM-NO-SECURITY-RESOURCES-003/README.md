# CSE-FEDRAMP-PM-NO-SECURITY-RESOURCES-003

**No Information Security Resources**

## Signal Overview

| Field           | Value                                          |
|-----------------|------------------------------------------------|
| Identifier      | `CSE-FEDRAMP-PM-NO-SECURITY-RESOURCES-003`     |
| Domain          | FEDRAMP                                        |
| Category        | PM                                             |
| Status          | Active                                         |
| Introduced In   | 1.0.0                                          |

## Description

Resources required to implement the information security program are not identified, allocated, or managed.

This signal indicates that the organization may lack adequate capital and operational resources (budget, personnel, tools, facilities) necessary to develop, implement, and sustain an effective information security program.

## Applicability

This signal applies to:

- Cloud Service Providers (CSPs) pursuing FedRAMP authorization
- Federal agencies managing information systems
- Third Party Assessment Organizations (3PAOs) conducting assessments
- Federal information systems processing, storing, or transmitting federal data
- Organizations supporting federal cloud services

## FedRAMP Context (Informative)

### Control Family
Program Management (PM)

### Control
PM-3: Information Security Resources

### Baseline
Low, Moderate, High

### NIST SP 800-53 Rev. 5
The organization:
- Includes the resources needed to implement the information security program in capital planning and investment requests and documents all exceptions to this requirement
- Prepares documentation required for addressing information security programs in capital planning and investment requests in accordance with applicable laws, executive orders, directives, policies, regulations, standards, and guidelines
- Makes available for expenditure, the planned information security resources
- Employs a business case or other rationale for information security resource allocations that align with organizational mission and business functions

These references are informative and do not constitute compliance guidance.

## Notes

Detection of this signal typically involves:

- Review of capital planning and investment request documentation
- Analysis of information security budget allocations and expenditures
- Verification of security resource alignment with capital planning processes
- Assessment of staffing levels and personnel qualifications
- Examination of security tools, technologies, and infrastructure investments
- Review of business cases and justifications for security resource requests
- Verification of resource availability and expenditure authority
- Assessment of resource adequacy relative to program scope and risk profile
- Evaluation of resource alignment with organizational mission and business functions
- Review of documentation for resource allocation exceptions

The presence of this signal indicates a condition that warrants review in the context of FedRAMP program management requirements.
