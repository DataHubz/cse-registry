# CSE-FEDRAMP-SC-NO-SC-POLICY-001

**No System and Communications Protection Policy**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-FEDRAMP-SC-NO-SC-POLICY-001`        |
| Domain          | FEDRAMP                                  |
| Category        | SC                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

System and communications protection policy and procedures are not developed, documented, and maintained.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** System and Communications Protection (SC)
**Control:** SC-1
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Develop, document, and disseminate a system and communications protection policy that addresses purpose, scope, roles, responsibilities, management commitment, coordination among organizational entities, and compliance; and procedures to facilitate the implementation of the system and communications protection policy and the associated system and communications protection controls."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing system and communications protection policy documentation, outdated procedures, lack of policy dissemination evidence, absence of defined roles and responsibilities for system and communications protection, and no coordination mechanisms across organizational entities.
