# CSE-FEDRAMP-CA-NO-CONTINUOUS-MONITORING-006

**No Continuous Monitoring**

## Signal Overview

| Field           | Value                                            |
|-----------------|--------------------------------------------------|
| Identifier      | `CSE-FEDRAMP-CA-NO-CONTINUOUS-MONITORING-006`    |
| Domain          | FEDRAMP                                          |
| Category        | CA                                               |
| Status          | Active                                           |
| Introduced In   | 1.0.0                                            |

## Description

The organization lacks a continuous monitoring strategy or program to maintain ongoing awareness of information security, vulnerabilities, and threats to support organizational risk management decisions.

This signal indicates the absence of processes for continuous monitoring of security controls, which is a critical requirement for maintaining FedRAMP authorization and ensuring that security posture remains effective over time.

## Applicability

This signal applies to:

- Cloud Service Providers (CSPs) seeking FedRAMP authorization
- Federal agencies implementing cloud services
- Third Party Assessment Organizations (3PAOs) conducting assessments
- Federal information systems requiring authorization

## FedRAMP Context (Informative)

**Control Family:** Security Assessment and Authorization (CA)

**Control:** CA-7 - Continuous Monitoring

**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "The organization develops a continuous monitoring strategy and implements a continuous monitoring program that includes: (a) Establishment of [Assignment: organization-defined metrics] to be monitored; (b) Establishment of [Assignment: organization-defined frequencies] for monitoring and [Assignment: organization-defined frequencies] for assessments supporting such monitoring; (c) Ongoing security control assessments in accordance with the organizational continuous monitoring strategy; (d) Ongoing security status monitoring of organization-defined metrics in accordance with the organizational continuous monitoring strategy; (e) Correlation and analysis of security-related information generated by assessments and monitoring; (f) Response actions to address results of the analysis of security-related information; and (g) Reporting the security status of organization and the information system to [FedRAMP Assignment: to meet Federal and FedRAMP requirements] [FedRAMP Assignment: in accordance with FedRAMP requirements]."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance:

- Verify the existence of a documented continuous monitoring strategy
- Check for defined metrics that are continuously monitored (vulnerability scans, configuration assessments, etc.)
- Confirm that monitoring frequencies are established and followed (monthly POA&M updates, annual assessments)
- Review evidence of ongoing security control assessments beyond the initial authorization
- Validate that security status is continuously monitored through automated tools where possible
- Examine processes for correlation and analysis of security-related information from multiple sources
- Check for documented response actions based on continuous monitoring findings
- Verify that security status reports are submitted to FedRAMP PMO as required
- Confirm integration between continuous monitoring and incident response processes
- Review automated scanning results (vulnerability scans, configuration compliance checks)
- Validate that continuous monitoring includes all required FedRAMP deliverables (monthly POA&M, annual assessment, significant change requests)
