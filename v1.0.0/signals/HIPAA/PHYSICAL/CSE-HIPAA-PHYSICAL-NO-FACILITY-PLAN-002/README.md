# CSE-HIPAA-PHYSICAL-NO-FACILITY-PLAN-002

**No Facility Security Plan**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HIPAA-PHYSICAL-NO-FACILITY-PLAN-002` |
| Domain          | HIPAA                                    |
| Category        | PHYSICAL                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No policies and procedures to safeguard the facility and equipment from unauthorized physical access, tampering, and theft.

## Applicability

This signal applies to:

- Healthcare facilities and data centers
- Server rooms and network closets
- Workstations and portable devices accessing ePHI
- Storage media containing ePHI
- Physical access control systems

## HIPAA Context (Informative)

**CFR Reference:** 45 CFR 164.310(a)(2)(ii)
**Requirement Type:** Addressable

**Regulatory Text:** "Implement policies and procedures to safeguard the facility and the equipment therein from unauthorized physical access, tampering, and theft."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Examine facility security documentation for comprehensive policies addressing physical access controls, anti-tampering measures, and theft prevention. Review physical security assessments, perimeter security controls, surveillance systems, and alarm systems. Verify that procedures address all areas where ePHI is accessed, stored, or transmitted.
