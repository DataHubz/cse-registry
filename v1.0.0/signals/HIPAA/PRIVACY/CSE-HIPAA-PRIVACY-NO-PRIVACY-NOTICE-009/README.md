# CSE-HIPAA-PRIVACY-NO-PRIVACY-NOTICE-009

**No Notice of Privacy Practices**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HIPAA-PRIVACY-NO-PRIVACY-NOTICE-009` |
| Domain          | HIPAA                                    |
| Category        | PRIVACY                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No Notice of Privacy Practices provided to individuals.

## Applicability

This signal applies to:

- Healthcare providers with direct patient relationships
- Health plans and insurers
- Healthcare clearinghouses
- Business associates handling PHI
- Patient-facing systems and portals
- Marketing and communications functions

## HIPAA Context (Informative)

**CFR Reference:** 45 CFR 164.520

**Regulatory Text:** "A covered entity must provide a notice that is written in plain language and that contains the elements required by this section. The notice must be provided to individuals as specified in paragraph (c) of this section."

These references are informative and do not constitute compliance guidance.

## Notes

Detection of this signal may occur when:
- Covered entities fail to develop or maintain a Notice of Privacy Practices
- Notice is not available for distribution to individuals
- Notice has not been updated to reflect material changes in privacy practices
- Electronic notice availability requirements are not met for entities with web presence
- Notice is not available in the language or format needed by the individual population served
- Documentation of notice provision is not maintained
