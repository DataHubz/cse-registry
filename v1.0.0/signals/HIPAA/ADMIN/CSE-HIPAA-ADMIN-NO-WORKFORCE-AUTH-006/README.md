# CSE-HIPAA-ADMIN-NO-WORKFORCE-AUTH-006

**No Workforce Authorization/Supervision**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HIPAA-ADMIN-NO-WORKFORCE-AUTH-006` |
| Domain          | HIPAA                                    |
| Category        | ADMIN                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No procedures exist for authorizing and/or supervising workforce members who work with electronic protected health information (ePHI) or in locations where it might be accessed.

This signal indicates the absence of documented processes to ensure workforce members have appropriate authorization before accessing ePHI and are supervised appropriately.

## Applicability

This signal applies to:

- Covered entities (healthcare providers, health plans, healthcare clearinghouses)
- Business associates handling ePHI
- Health information systems and EHR platforms
- Cloud service providers hosting ePHI
- IT infrastructure supporting healthcare operations

## HIPAA Context (Informative)

**CFR Reference:** 45 CFR 164.308(a)(3)(ii)(A)
**Requirement Type:** Addressable

**Regulatory Text:** "Implement procedures for the authorization and/or supervision of workforce members who work with electronic protected health information or in locations where it might be accessed."

These references are informative and do not constitute compliance guidance.

## Notes

Detection of this signal typically involves:

- Review of workforce authorization procedures and documentation
- Examination of supervision policies and practices
- Analysis of access approval workflows
- Verification of authorization records for ePHI access
- Assessment of supervision mechanisms for workforce members

The presence of this signal indicates inadequate controls over workforce access to and handling of ePHI.
