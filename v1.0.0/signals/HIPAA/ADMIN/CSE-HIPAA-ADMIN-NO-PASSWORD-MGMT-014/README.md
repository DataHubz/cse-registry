# CSE-HIPAA-ADMIN-NO-PASSWORD-MGMT-014

**No Password Management**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HIPAA-ADMIN-NO-PASSWORD-MGMT-014` |
| Domain          | HIPAA                                    |
| Category        | ADMIN                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No procedures exist for creating, changing, and safeguarding passwords used to authenticate users and protect electronic protected health information (ePHI).

This signal indicates the absence of documented password management practices to ensure secure authentication to ePHI systems.

## Applicability

This signal applies to:

- Covered entities (healthcare providers, health plans, healthcare clearinghouses)
- Business associates handling ePHI
- Health information systems and EHR platforms
- Cloud service providers hosting ePHI
- IT infrastructure supporting healthcare operations

## HIPAA Context (Informative)

**CFR Reference:** 45 CFR 164.308(a)(5)(ii)(D)
**Requirement Type:** Addressable

**Regulatory Text:** "Implement procedures for creating, changing, and safeguarding passwords."

These references are informative and do not constitute compliance guidance.

## Notes

Detection of this signal typically involves:

- Review of password management policies and procedures
- Examination of password complexity and expiration requirements
- Analysis of password creation and change workflows
- Verification of password storage and transmission security
- Assessment of password safeguarding practices and user education

The presence of this signal indicates that weak or compromised passwords may provide unauthorized access to ePHI.
