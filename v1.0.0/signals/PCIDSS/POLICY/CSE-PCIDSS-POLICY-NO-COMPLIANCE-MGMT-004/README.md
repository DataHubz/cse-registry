# CSE-PCIDSS-POLICY-NO-COMPLIANCE-MGMT-004

**No Compliance Management**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-PCIDSS-POLICY-NO-COMPLIANCE-MGMT-004` |
| Domain          | PCIDSS                                   |
| Category        | POLICY                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No processes for managing ongoing PCI DSS compliance.

## Applicability

This signal applies to:

- Organizations processing, storing, or transmitting cardholder data
- Security and compliance teams
- Human resources and training departments
- Third-party service providers (TPSPs)
- Incident response teams

## PCI DSS Context (Informative)

**Requirement:** 12.4 - PCI DSS compliance is managed

**Sub-Requirement:** 12.4.1

**Regulatory Text:** "Additional requirement for service providers only: Responsibility is established by executive management for the protection of cardholder data and a PCI DSS compliance program to include: Overall accountability for maintaining PCI DSS compliance, and defining a charter for a PCI DSS compliance program and communication to executive management."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: For service providers, verify executive-level responsibility for PCI DSS compliance and documented compliance program charter. For all entities, monitor for compliance tracking mechanisms, quarterly and annual assessment schedules, and remediation management processes.
