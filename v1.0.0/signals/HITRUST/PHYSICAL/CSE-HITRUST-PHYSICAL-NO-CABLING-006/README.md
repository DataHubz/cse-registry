# CSE-HITRUST-PHYSICAL-NO-CABLING-006

**Cabling Security Missing**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HITRUST-PHYSICAL-NO-CABLING-006` |
| Domain          | HITRUST                                  |
| Category        | PHYSICAL                                 |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No security measures in place to protect power and telecommunications cabling carrying data or supporting information services from interception, interference, or damage.

## Applicability

This signal applies to:

- Network cabling infrastructure
- Power cabling for critical systems
- Telecommunications lines
- Fiber optic connections
- Data center structured cabling

## HITRUST Context (Informative)

**Control Domain:** 08 - Physical and Environmental Security

**Reference:** 08.f

**Regulatory Text:** "Power and telecommunications cabling carrying data or supporting information services shall be protected from interception, interference or damage."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review cabling security measures including use of conduits, cable trays, locked cabinets, and secure pathways. Verify that network and power cables are protected from physical damage, unauthorized tapping, or electromagnetic interference. Check for separation of power and data cables, proper cable management in secure areas, and controls preventing unauthorized access to telecommunications lines or network infrastructure.
