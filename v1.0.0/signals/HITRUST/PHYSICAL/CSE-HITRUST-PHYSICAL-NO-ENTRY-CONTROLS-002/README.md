# CSE-HITRUST-PHYSICAL-NO-ENTRY-CONTROLS-002

**Physical Entry Controls Missing**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HITRUST-PHYSICAL-NO-ENTRY-CONTROLS-002` |
| Domain          | HITRUST                                  |
| Category        | PHYSICAL                                 |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No physical entry controls in place to ensure only authorized personnel are allowed access to secure areas.

## Applicability

This signal applies to:

- Data centers and server rooms
- Secure areas containing sensitive information
- Information processing facilities
- Storage areas for sensitive media
- Restricted access zones within facilities

## HITRUST Context (Informative)

**Control Domain:** 08 - Physical and Environmental Security

**Reference:** 08.b

**Regulatory Text:** "Secure areas shall be protected by appropriate entry controls to ensure that only authorized personnel are allowed access."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review physical access control systems including badge readers, biometric systems, or key-based entry. Verify that entry controls are implemented at all secure area entry points. Check for documented procedures governing access authorization, visitor management, and entry logging. Confirm that access is granted based on business need and role-based authorization.
