# CSE-NISTCSF-AA-NO-PHYSICAL-ACCESS-006

**No Physical Access Controls**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AA-NO-PHYSICAL-ACCESS-006` |
| Domain          | NISTCSF                                  |
| Category        | AA                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Physical access to assets is not managed, monitored, and enforced.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Identity and access management teams
- Security awareness and training programs
- Organizations managing user authentication

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** Identity Management, Authentication, and Access Control
**Subcategory:** PR.AA-06

**Framework Text:** "Physical access to assets is managed, monitored, and enforced commensurate with risk"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Identify facilities, data centers, and equipment locations where physical access controls are absent or inadequate, including lack of access management procedures, missing monitoring capabilities (such as surveillance or access logs), or insufficient enforcement mechanisms relative to the criticality and sensitivity of assets.
