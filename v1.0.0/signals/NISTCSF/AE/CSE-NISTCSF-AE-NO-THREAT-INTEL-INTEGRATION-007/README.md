# CSE-NISTCSF-AE-NO-THREAT-INTEL-INTEGRATION-007

**No Threat Intelligence Integration**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AE-NO-THREAT-INTEL-INTEGRATION-007` |
| Domain          | NISTCSF                                  |
| Category        | AE                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Cyber threat intelligence is not integrated into the analysis.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity detection capabilities
- Security operations and monitoring teams
- Threat detection and analysis functions
- Organizations with continuous monitoring requirements

## NIST CSF 2.0 Context (Informative)

**Function:** DETECT (DE)
**Category:** DE.AE - Adverse Event Analysis
**Subcategory:** DE.AE-07

**Framework Text:** "Cyber threat intelligence and other contextual information are integrated into the analysis"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Organizations should integrate cyber threat intelligence from internal and external sources, including threat actor tactics, techniques, and procedures (TTPs), indicators of compromise (IOCs), vulnerability information, and industry-specific threat data. This contextual information enhances the analysis of adverse events and improves detection accuracy and response effectiveness.
