# CSE-NISTCSF-RA-NO-SUPPLIER-ASSESSMENT-010

**No Supplier Assessment**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-RA-NO-SUPPLIER-ASSESSMENT-010` |
| Domain          | NISTCSF                                  |
| Category        | RA                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Critical suppliers are not assessed prior to acquisition.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity risk management
- Risk assessment and vulnerability management teams
- Security operations and threat intelligence functions
- Organizations conducting security assessments

## NIST CSF 2.0 Context (Informative)

**Function:** IDENTIFY (ID)
**Category:** ID.RA - Risk Assessment
**Subcategory:** ID.RA-10

**Framework Text:** "Critical suppliers are assessed prior to acquisition"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: This signal indicates that third-party and supplier risk assessment processes are not performed before establishing critical vendor relationships. Organizations should implement vendor risk assessment programs that evaluate supplier security posture, compliance status, and risk management capabilities prior to procurement decisions.
