# CSE-NISTCSF-RA-NO-HW-SW-INTEGRITY-009

**No Hardware and Software Integrity Assessment**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-RA-NO-HW-SW-INTEGRITY-009` |
| Domain          | NISTCSF                                  |
| Category        | RA                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

The authenticity and integrity of hardware and software are not assessed prior to acquisition.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity risk management
- Risk assessment and vulnerability management teams
- Security operations and threat intelligence functions
- Organizations conducting security assessments

## NIST CSF 2.0 Context (Informative)

**Function:** IDENTIFY (ID)
**Category:** ID.RA - Risk Assessment
**Subcategory:** ID.RA-09

**Framework Text:** "The authenticity and integrity of hardware and software are assessed prior to acquisition and use"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: This signal indicates that supply chain risk assessment processes for hardware and software are not in place. Organizations should implement verification procedures including cryptographic hash validation, digital signature verification, trusted supplier validation, and supply chain provenance checks before deploying new technology assets.
