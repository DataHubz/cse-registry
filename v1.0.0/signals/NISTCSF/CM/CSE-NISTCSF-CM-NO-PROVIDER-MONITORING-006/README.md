# CSE-NISTCSF-CM-NO-PROVIDER-MONITORING-006

**No External Service Provider Monitoring**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-CM-NO-PROVIDER-MONITORING-006` |
| Domain          | NISTCSF                                  |
| Category        | CM                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

External service provider activities are not monitored for potentially adverse events.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity detection capabilities
- Security operations and monitoring teams
- Threat detection and analysis functions
- Organizations with continuous monitoring requirements

## NIST CSF 2.0 Context (Informative)

**Function:** DETECT (DE)
**Category:** DE.CM - Continuous Monitoring
**Subcategory:** DE.CM-06

**Framework Text:** "External service provider activities and services are monitored to find potentially adverse events"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Organizations should monitor activities of cloud service providers, managed service providers, vendors, and other third parties with access to systems or data. This includes reviewing service provider logs, monitoring API usage, tracking data transfers, and validating compliance with security requirements to detect potentially adverse events originating from or affecting external service providers.
