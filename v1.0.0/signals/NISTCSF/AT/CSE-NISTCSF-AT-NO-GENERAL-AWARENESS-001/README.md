# CSE-NISTCSF-AT-NO-GENERAL-AWARENESS-001

**No General Cybersecurity Awareness**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AT-NO-GENERAL-AWARENESS-001` |
| Domain          | NISTCSF                                  |
| Category        | AT                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Personnel are not provided with awareness and training for general tasks.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Identity and access management teams
- Security awareness and training programs
- Organizations managing user authentication

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** Awareness and Training
**Subcategory:** PR.AT-01

**Framework Text:** "Personnel are provided with awareness and training so that they possess the knowledge and skills to perform general tasks with cybersecurity risks in mind"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Identify organizations or departments where general cybersecurity awareness programs are absent, including lack of security training for all personnel on common threats (phishing, social engineering, password security), missing onboarding security education, or no regular awareness campaigns to reinforce secure behaviors.
