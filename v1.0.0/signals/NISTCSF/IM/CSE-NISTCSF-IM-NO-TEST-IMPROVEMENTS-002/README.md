# CSE-NISTCSF-IM-NO-TEST-IMPROVEMENTS-002

**Improvements Not Identified from Security Tests and Exercises**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-IM-NO-TEST-IMPROVEMENTS-002` |
| Domain          | NISTCSF                                  |
| Category        | IM                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Improvements are not identified from security tests and exercises.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity risk management
- Continuous improvement and process optimization teams
- Security testing and assessment functions
- Organizations conducting lessons learned activities

## NIST CSF 2.0 Context (Informative)

**Function:** IDENTIFY (ID)
**Category:** ID.IM - Improvement
**Subcategory:** ID.IM-02

**Framework Text:** "Improvements are identified from security tests and exercises, including those done in coordination with suppliers and relevant third parties"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for absence of post-exercise analysis, lack of documented findings from penetration tests or tabletop exercises, failure to capture lessons learned from supplier security assessments, or missing action items following security testing activities.
