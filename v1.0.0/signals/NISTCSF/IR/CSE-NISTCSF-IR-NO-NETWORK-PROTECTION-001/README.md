# CSE-NISTCSF-IR-NO-NETWORK-PROTECTION-001

**Networks Not Protected from Unauthorized Access**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-IR-NO-NETWORK-PROTECTION-001` |
| Domain          | NISTCSF                                  |
| Category        | Technology Infrastructure Resilience     |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Networks and environments are not protected from unauthorized logical access.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Data protection and platform security teams
- Infrastructure resilience programs
- Organizations managing technology platforms

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** PR.IR - Technology Infrastructure Resilience
**Subcategory:** PR.IR-01

**Framework Text:** "Networks and environments are protected from unauthorized logical access and usage"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for missing network segmentation, inadequate firewall rules, lack of network access controls, absence of intrusion prevention systems, weak authentication for network resources, and insufficient protection against unauthorized network access.
