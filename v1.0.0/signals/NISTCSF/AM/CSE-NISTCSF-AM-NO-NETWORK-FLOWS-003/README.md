# CSE-NISTCSF-AM-NO-NETWORK-FLOWS-003

**No Network Communication and Data Flows Documented**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AM-NO-NETWORK-FLOWS-003` |
| Domain          | NISTCSF                                  |
| Category        | AM                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Representations of authorized network communication and data flows are not maintained.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity risk management
- IT asset management and inventory teams
- Configuration management programs
- Organizations maintaining technology inventories

## NIST CSF 2.0 Context (Informative)

**Function:** IDENTIFY (ID)
**Category:** ID.AM - Asset Management
**Subcategory:** ID.AM-03

**Framework Text:** "Representations of the organization's authorized network communication and internal and external network data flows are maintained"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for absence of network diagrams, missing data flow documentation, lack of network segmentation maps, or gaps in traffic pattern documentation. Organizations should maintain current representations including network topology diagrams, data flow diagrams, firewall rulesets, API communications, and third-party data exchanges.
