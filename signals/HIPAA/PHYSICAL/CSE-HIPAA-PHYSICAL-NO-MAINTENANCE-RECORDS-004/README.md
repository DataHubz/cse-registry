# CSE-HIPAA-PHYSICAL-NO-MAINTENANCE-RECORDS-004

**No Maintenance Records**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HIPAA-PHYSICAL-NO-MAINTENANCE-RECORDS-004` |
| Domain          | HIPAA                                    |
| Category        | PHYSICAL                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No documentation of repairs and modifications to physical components of a facility related to security.

## Applicability

This signal applies to:

- Healthcare facilities and data centers
- Server rooms and network closets
- Workstations and portable devices accessing ePHI
- Storage media containing ePHI
- Physical access control systems

## HIPAA Context (Informative)

**CFR Reference:** 45 CFR 164.310(a)(2)(iv)
**Requirement Type:** Addressable

**Regulatory Text:** "Implement policies and procedures to document repairs and modifications to the physical components of a facility which are related to security (for example, hardware, walls, doors, and locks)."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review maintenance logs and work order systems for documentation of security-related facility modifications. Verify that records exist for repairs or changes to locks, doors, walls, access control systems, surveillance equipment, and other physical security components. Check for procedures requiring documentation before and after security-related maintenance activities.
