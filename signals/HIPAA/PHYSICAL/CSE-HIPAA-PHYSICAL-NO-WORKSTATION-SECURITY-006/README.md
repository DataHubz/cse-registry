# CSE-HIPAA-PHYSICAL-NO-WORKSTATION-SECURITY-006

**No Workstation Security**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HIPAA-PHYSICAL-NO-WORKSTATION-SECURITY-006` |
| Domain          | HIPAA                                    |
| Category        | PHYSICAL                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No physical safeguards for workstations to restrict access to authorized users only.

## Applicability

This signal applies to:

- Healthcare facilities and data centers
- Server rooms and network closets
- Workstations and portable devices accessing ePHI
- Storage media containing ePHI
- Physical access control systems

## HIPAA Context (Informative)

**CFR Reference:** 45 CFR 164.310(c)
**Requirement Type:** Required

**Regulatory Text:** "Implement physical safeguards for all workstations that access electronic protected health information, to restrict access to authorized users."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Assess physical security controls for workstations accessing ePHI. Verify implementation of safeguards such as locking mechanisms, secure mounting, cable locks, proximity sensors, or placement in restricted access areas. Check for controls preventing unauthorized physical access to workstations, including laptop security, screen positioning, and automatic lock features when unattended.
