# CSE-HIPAA-PHYSICAL-NO-CONTINGENCY-OPS-001

**No Contingency Operations**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HIPAA-PHYSICAL-NO-CONTINGENCY-OPS-001` |
| Domain          | HIPAA                                    |
| Category        | PHYSICAL                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No procedures allowing facility access in support of restoration of lost data under the disaster recovery plan and emergency mode operations plan.

## Applicability

This signal applies to:

- Healthcare facilities and data centers
- Server rooms and network closets
- Workstations and portable devices accessing ePHI
- Storage media containing ePHI
- Physical access control systems

## HIPAA Context (Informative)

**CFR Reference:** 45 CFR 164.310(a)(2)(i)
**Requirement Type:** Addressable

**Regulatory Text:** "Establish (and implement as needed) procedures that allow facility access in support of restoration of lost data under the disaster recovery plan and emergency mode operations plan in the event of an emergency."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review policies and procedures for emergency facility access controls. Verify that documented procedures exist for granting physical access during disaster recovery operations and emergency mode operations. Check for integration with the organization's disaster recovery and business continuity plans.
