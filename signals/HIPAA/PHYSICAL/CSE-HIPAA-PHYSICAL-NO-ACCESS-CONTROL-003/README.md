# CSE-HIPAA-PHYSICAL-NO-ACCESS-CONTROL-003

**No Access Control and Validation Procedures**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HIPAA-PHYSICAL-NO-ACCESS-CONTROL-003` |
| Domain          | HIPAA                                    |
| Category        | PHYSICAL                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No procedures to control and validate physical access based on role or function, including visitor control.

## Applicability

This signal applies to:

- Healthcare facilities and data centers
- Server rooms and network closets
- Workstations and portable devices accessing ePHI
- Storage media containing ePHI
- Physical access control systems

## HIPAA Context (Informative)

**CFR Reference:** 45 CFR 164.310(a)(2)(iii)
**Requirement Type:** Addressable

**Regulatory Text:** "Implement procedures to control and validate a person's access to facilities based on their role or function, including visitor control, and control of access to software programs for testing and revision."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review physical access control procedures including badge systems, visitor logs, and escort requirements. Verify that access is granted based on role-based authorization and that validation mechanisms are in place. Check for documented visitor management procedures, sign-in/sign-out logs, and controls for accessing areas with development or testing systems.
