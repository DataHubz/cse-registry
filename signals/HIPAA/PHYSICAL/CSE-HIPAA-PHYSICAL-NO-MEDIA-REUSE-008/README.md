# CSE-HIPAA-PHYSICAL-NO-MEDIA-REUSE-008

**No Media Re-use Controls**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HIPAA-PHYSICAL-NO-MEDIA-REUSE-008` |
| Domain          | HIPAA                                    |
| Category        | PHYSICAL                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No procedures for removal of ePHI before media re-use.

## Applicability

This signal applies to:

- Healthcare facilities and data centers
- Server rooms and network closets
- Workstations and portable devices accessing ePHI
- Storage media containing ePHI
- Physical access control systems

## HIPAA Context (Informative)

**CFR Reference:** 45 CFR 164.310(d)(2)(ii)
**Requirement Type:** Required

**Regulatory Text:** "Implement procedures for removal of electronic protected health information from electronic media before the media are made available for re-use."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review procedures for sanitizing storage media before reallocation or repurposing. Verify that documented processes exist for securely removing ePHI from media intended for re-use, including formatting, wiping, or cryptographic erasure methods. Check for procedures addressing different media types and verification of successful data removal before media is reassigned or released.
