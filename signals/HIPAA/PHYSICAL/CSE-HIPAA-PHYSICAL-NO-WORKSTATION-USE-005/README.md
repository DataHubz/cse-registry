# CSE-HIPAA-PHYSICAL-NO-WORKSTATION-USE-005

**No Workstation Use Policy**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HIPAA-PHYSICAL-NO-WORKSTATION-USE-005` |
| Domain          | HIPAA                                    |
| Category        | PHYSICAL                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No policies and procedures specifying proper functions, manner of performance, and physical surroundings for workstations accessing ePHI.

## Applicability

This signal applies to:

- Healthcare facilities and data centers
- Server rooms and network closets
- Workstations and portable devices accessing ePHI
- Storage media containing ePHI
- Physical access control systems

## HIPAA Context (Informative)

**CFR Reference:** 45 CFR 164.310(b)
**Requirement Type:** Required

**Regulatory Text:** "Implement policies and procedures that specify the proper functions to be performed, the manner in which those functions are to be performed, and the physical attributes of the surroundings of a specific workstation or class of workstation that can access electronic protected health information."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review organizational policies for workstation use controls. Verify that documented procedures specify allowable functions for workstations accessing ePHI, proper usage protocols, and requirements for physical placement and surroundings. Check for policies addressing privacy screens, workstation positioning to prevent unauthorized viewing, and secure areas for workstations handling sensitive ePHI.
