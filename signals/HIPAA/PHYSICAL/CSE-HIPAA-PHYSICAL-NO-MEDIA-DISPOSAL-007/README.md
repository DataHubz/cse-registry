# CSE-HIPAA-PHYSICAL-NO-MEDIA-DISPOSAL-007

**No Media Disposal**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HIPAA-PHYSICAL-NO-MEDIA-DISPOSAL-007` |
| Domain          | HIPAA                                    |
| Category        | PHYSICAL                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No policies and procedures for final disposition of ePHI and/or storage media.

## Applicability

This signal applies to:

- Healthcare facilities and data centers
- Server rooms and network closets
- Workstations and portable devices accessing ePHI
- Storage media containing ePHI
- Physical access control systems

## HIPAA Context (Informative)

**CFR Reference:** 45 CFR 164.310(d)(2)(i)
**Requirement Type:** Required

**Regulatory Text:** "Implement policies and procedures to address the final disposition of electronic protected health information, and/or the hardware or electronic media on which it is stored."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review media disposal and sanitization policies and procedures. Verify that documented processes exist for secure destruction or disposal of ePHI and storage media, including hard drives, backup tapes, CDs/DVDs, USB drives, and mobile devices. Check for procedures addressing physical destruction, degaussing, cryptographic erasure, or certified data destruction services with certificates of destruction.
