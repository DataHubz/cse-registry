# CSE-HIPAA-TECH-NO-EMERGENCY-ACCESS-002

**No Emergency Access Procedure**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HIPAA-TECH-NO-EMERGENCY-ACCESS-002` |
| Domain          | HIPAA                                    |
| Category        | TECH                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No procedures for obtaining necessary ePHI during an emergency.

## Applicability

This signal applies to:

- Electronic health record (EHR) systems
- Health information exchanges (HIEs)
- Patient portals and healthcare applications
- Database systems containing ePHI
- Network infrastructure transmitting ePHI
- Cloud services hosting healthcare data

## HIPAA Context (Informative)

**CFR Reference:** 45 CFR 164.312(a)(2)(ii)
**Requirement Type:** Required

**Regulatory Text:** "Emergency access procedure (Required). Establish (and implement as needed) procedures for obtaining necessary electronic protected health information during an emergency."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review system documentation and incident response procedures to verify the existence of emergency access protocols. Check for documented procedures that allow authorized personnel to access ePHI during system failures, disasters, or other emergency situations. Verify that emergency access mechanisms are tested and that access is properly logged and audited.
