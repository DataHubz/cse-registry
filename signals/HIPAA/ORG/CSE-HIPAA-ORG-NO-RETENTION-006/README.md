# CSE-HIPAA-ORG-NO-RETENTION-006

**No 6-Year Retention**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HIPAA-ORG-NO-RETENTION-006` |
| Domain          | HIPAA                                    |
| Category        | ORG                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Documentation not retained for 6 years from date of creation or when last in effect.

## Applicability

This signal applies to:

- Covered entities and business associates
- Healthcare organizations with business associate relationships
- Group health plans and plan sponsors
- Organizations requiring HIPAA compliance documentation
- Vendor management and contract administration functions

## HIPAA Context (Informative)

**CFR Reference:** 45 CFR 164.316(b)(2)(i)
**Requirement Type:** Required

**Regulatory Text:** "Retain the documentation required by paragraph (b)(1) of this section for 6 years from the date of its creation or the date when it last was in effect, whichever is later."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review records retention policies and practices to ensure Security Rule documentation is retained for the required 6-year period. Examine document management systems for appropriate retention schedules. Verify that both current and superseded policies, procedures, and required documentation are retained. Assess whether retention periods are calculated correctly from the later of creation date or when the document was last in effect.
