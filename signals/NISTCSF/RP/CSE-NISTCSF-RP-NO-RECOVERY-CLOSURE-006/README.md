# CSE-NISTCSF-RP-NO-RECOVERY-CLOSURE-006

**Incident Recovery End Not Declared Based on Criteria**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-RP-NO-RECOVERY-CLOSURE-006` |
| Domain          | NISTCSF                                  |
| Category        | RP                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

The end of incident recovery is not declared based on criteria.

## Applicability

This signal applies to:

- All organizations with business continuity and disaster recovery requirements
- Incident recovery and restoration teams
- Communications and public relations functions
- Organizations with regulatory recovery requirements

## NIST CSF 2.0 Context (Informative)

**Function:** RECOVER (RC)
**Category:** RC.RP - Incident Recovery Plan Execution
**Subcategory:** RC.RP-06

**Framework Text:** "The end of incident recovery is declared based on criteria, and incident-related documentation is completed"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Identify incidents where recovery activities cease without formal closure declaration or documented completion criteria. Monitor for missing post-recovery documentation, lessons learned, or undefined exit criteria that leave recovery status ambiguous.
