# CSE-NISTCSF-RP-NO-RECOVERY-EXECUTION-001

**Incident Recovery Plan Not Executed**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-RP-NO-RECOVERY-EXECUTION-001` |
| Domain          | NISTCSF                                  |
| Category        | RP                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

The recovery portion of the incident response plan is not executed.

## Applicability

This signal applies to:

- All organizations with business continuity and disaster recovery requirements
- Incident recovery and restoration teams
- Communications and public relations functions
- Organizations with regulatory recovery requirements

## NIST CSF 2.0 Context (Informative)

**Function:** RECOVER (RC)
**Category:** RC.RP - Incident Recovery Plan Execution
**Subcategory:** RC.RP-01

**Framework Text:** "The recovery portion of the incident response plan is executed once initiated from the incident response process"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for incidents where the recovery phase is triggered but no documented recovery plan execution occurs, or when recovery activities proceed ad-hoc without following established procedures. Look for gaps between incident detection/containment and formal recovery initiation.
