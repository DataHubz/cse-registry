# CSE-NISTCSF-RCOM-NO-PUBLIC-UPDATES-004

**Public Updates on Incident Recovery Not Shared Using Approved Methods**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-RCOM-NO-PUBLIC-UPDATES-004` |
| Domain          | NISTCSF                                  |
| Category        | RCOM                                     |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Public updates on incident recovery are not shared using approved methods.

## Applicability

This signal applies to:

- All organizations with business continuity and disaster recovery requirements
- Incident recovery and restoration teams
- Communications and public relations functions
- Organizations with regulatory recovery requirements

## NIST CSF 2.0 Context (Informative)

**Function:** RECOVER (RC)
**Category:** RC.CO - Incident Recovery Communication
**Subcategory:** RC.CO-04

**Framework Text:** "Public updates on incident recovery are shared using approved methods and messaging"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Identify public-facing incidents where recovery communications bypass approved channels, lack pre-authorization, or use inconsistent messaging. Monitor for unauthorized social media posts, unapproved press releases, or communications that deviate from established crisis communication protocols.
