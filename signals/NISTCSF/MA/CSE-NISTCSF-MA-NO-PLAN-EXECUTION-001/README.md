# CSE-NISTCSF-MA-NO-PLAN-EXECUTION-001

**Incident Response Plan Not Executed with Third Parties**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-MA-NO-PLAN-EXECUTION-001` |
| Domain          | NISTCSF                                  |
| Category        | RS.MA                                    |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

The incident response plan is not executed in coordination with relevant third parties.

## Applicability

This signal applies to:

- All organizations with incident response capabilities
- Security operations and incident response teams
- Forensics and investigation functions
- Organizations with breach notification requirements

## NIST CSF 2.0 Context (Informative)

**Function:** RESPOND (RS)
**Category:** RS.MA - Incident Management
**Subcategory:** RS.MA-01

**Framework Text:** "The incident response plan is executed in coordination with relevant third parties once an incident is declared"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for incidents where third-party stakeholders (vendors, service providers, law enforcement, regulatory bodies) were not notified or coordinated with during incident response execution. Look for gaps in communication logs, missing escalation records to external parties, or incomplete incident response documentation that should reference third-party coordination activities.
