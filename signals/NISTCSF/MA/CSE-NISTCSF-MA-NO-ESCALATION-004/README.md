# CSE-NISTCSF-MA-NO-ESCALATION-004

**Incidents Not Escalated or Elevated as Needed**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-MA-NO-ESCALATION-004` |
| Domain          | NISTCSF                                  |
| Category        | RS.MA                                    |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Incidents are not escalated or elevated as needed.

## Applicability

This signal applies to:

- All organizations with incident response capabilities
- Security operations and incident response teams
- Forensics and investigation functions
- Organizations with breach notification requirements

## NIST CSF 2.0 Context (Informative)

**Function:** RESPOND (RS)
**Category:** RS.MA - Incident Management
**Subcategory:** RS.MA-04

**Framework Text:** "Incidents are escalated or elevated as needed"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Identify high-severity incidents that remain at lower response tiers, critical events not reported to management or executive teams, incidents exceeding SLA thresholds without escalation, or missing escalation paths in incident workflows. Monitor for indicators that incident scope or impact has grown but response level has not adjusted accordingly.
