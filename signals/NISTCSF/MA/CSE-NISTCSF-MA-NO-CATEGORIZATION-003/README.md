# CSE-NISTCSF-MA-NO-CATEGORIZATION-003

**Incidents Not Categorized and Prioritized**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-MA-NO-CATEGORIZATION-003` |
| Domain          | NISTCSF                                  |
| Category        | RS.MA                                    |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Incidents are not categorized and prioritized.

## Applicability

This signal applies to:

- All organizations with incident response capabilities
- Security operations and incident response teams
- Forensics and investigation functions
- Organizations with breach notification requirements

## NIST CSF 2.0 Context (Informative)

**Function:** RESPOND (RS)
**Category:** RS.MA - Incident Management
**Subcategory:** RS.MA-03

**Framework Text:** "Incidents are categorized and prioritized"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Look for incidents missing category assignments (e.g., malware, phishing, data breach, unauthorized access) or priority/severity ratings. Monitor for tickets without impact classifications, incidents handled in FIFO order rather than risk-based prioritization, or missing fields in incident tracking systems for category and priority metadata.
