# CSE-NISTCSF-AA-NO-IDENTITY-MGMT-001

**No Identity Management**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AA-NO-IDENTITY-MGMT-001` |
| Domain          | NISTCSF                                  |
| Category        | AA                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Identities and credentials for authorized users, services, and hardware are not managed.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Identity and access management teams
- Security awareness and training programs
- Organizations managing user authentication

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** Identity Management, Authentication, and Access Control
**Subcategory:** PR.AA-01

**Framework Text:** "Identities and credentials for authorized users, services, and hardware are managed by the organization"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Identify systems and environments where identity lifecycle management processes are absent or inadequate, including lack of credential provisioning, modification, and deprovisioning procedures for users, services, and hardware devices.
