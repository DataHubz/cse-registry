# CSE-NISTCSF-AA-NO-AUTHENTICATION-003

**No Authentication**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AA-NO-AUTHENTICATION-003` |
| Domain          | NISTCSF                                  |
| Category        | AA                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Users, services, and hardware are not authenticated.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Identity and access management teams
- Security awareness and training programs
- Organizations managing user authentication

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** Identity Management, Authentication, and Access Control
**Subcategory:** PR.AA-03

**Framework Text:** "Users, services, and hardware are authenticated"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Identify systems and services that lack authentication mechanisms or allow unauthenticated access to resources, including missing authentication requirements for users, service accounts, APIs, and hardware devices before granting access to systems or data.
