# CSE-NISTCSF-AA-NO-IDENTITY-PROOFING-002

**No Identity Proofing**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AA-NO-IDENTITY-PROOFING-002` |
| Domain          | NISTCSF                                  |
| Category        | AA                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Identities are not proofed and bound to credentials based on context.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Identity and access management teams
- Security awareness and training programs
- Organizations managing user authentication

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** Identity Management, Authentication, and Access Control
**Subcategory:** PR.AA-02

**Framework Text:** "Identities are proofed and bound to credentials based on the context of interactions"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Identify authentication systems where identity verification processes are missing or insufficient, including lack of identity proofing procedures that validate user claims before credential issuance and inadequate binding of verified identities to authentication credentials based on risk context.
