# CSE-NISTCSF-PS-NO-SOFTWARE-MAINTENANCE-002

**Software Not Properly Maintained**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-PS-NO-SOFTWARE-MAINTENANCE-002` |
| Domain          | NISTCSF                                  |
| Category        | Platform Security                        |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Software is not maintained, replaced, and removed commensurate with risk.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Data protection and platform security teams
- Infrastructure resilience programs
- Organizations managing technology platforms

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** PR.PS - Platform Security
**Subcategory:** PR.PS-02

**Framework Text:** "Software is maintained, replaced, and removed commensurate with risk"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for outdated software versions, missing security patches, unsupported software still in use, lack of software lifecycle management, failure to remove deprecated applications, and inadequate vulnerability remediation processes.
