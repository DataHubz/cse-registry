# CSE-NISTCSF-PS-NO-SECURE-DEV-006

**Secure Development Practices Not Integrated**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-PS-NO-SECURE-DEV-006` |
| Domain          | NISTCSF                                  |
| Category        | Platform Security                        |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Secure software development practices are not integrated.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Data protection and platform security teams
- Infrastructure resilience programs
- Organizations managing technology platforms

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** PR.PS - Platform Security
**Subcategory:** PR.PS-06

**Framework Text:** "Secure software development practices are integrated, and their performance is monitored throughout the software development life cycle"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for lack of security requirements in development, missing secure coding standards, absence of code review processes, inadequate security testing, failure to track security metrics in SDLC, and missing security training for developers.
