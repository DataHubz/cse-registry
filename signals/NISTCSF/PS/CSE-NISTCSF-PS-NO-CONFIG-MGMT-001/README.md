# CSE-NISTCSF-PS-NO-CONFIG-MGMT-001

**Configuration Management Not Established**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-PS-NO-CONFIG-MGMT-001` |
| Domain          | NISTCSF                                  |
| Category        | Platform Security                        |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Configuration management practices are not established and applied.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Data protection and platform security teams
- Infrastructure resilience programs
- Organizations managing technology platforms

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** PR.PS - Platform Security
**Subcategory:** PR.PS-01

**Framework Text:** "Configuration management practices are established and applied"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for lack of configuration baselines, missing configuration change control processes, untracked system configurations, absence of configuration documentation, and failure to enforce secure configuration standards across platforms.
