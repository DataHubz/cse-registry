# CSE-NISTCSF-PS-NO-HARDWARE-MAINTENANCE-003

**Hardware Not Properly Maintained**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-PS-NO-HARDWARE-MAINTENANCE-003` |
| Domain          | NISTCSF                                  |
| Category        | Platform Security                        |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Hardware is not maintained, replaced, and removed commensurate with risk.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Data protection and platform security teams
- Infrastructure resilience programs
- Organizations managing technology platforms

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** PR.PS - Platform Security
**Subcategory:** PR.PS-03

**Framework Text:** "Hardware is maintained, replaced, and removed commensurate with risk"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for outdated firmware versions, end-of-life hardware still in production, lack of hardware lifecycle management, failure to sanitize hardware before disposal, missing hardware maintenance schedules, and inadequate tracking of hardware assets.
