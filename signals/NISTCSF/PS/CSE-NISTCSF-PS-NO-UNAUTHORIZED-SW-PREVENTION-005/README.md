# CSE-NISTCSF-PS-NO-UNAUTHORIZED-SW-PREVENTION-005

**Unauthorized Software Not Prevented**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-PS-NO-UNAUTHORIZED-SW-PREVENTION-005` |
| Domain          | NISTCSF                                  |
| Category        | Platform Security                        |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Installation and execution of unauthorized software are not prevented.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Data protection and platform security teams
- Infrastructure resilience programs
- Organizations managing technology platforms

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** PR.PS - Platform Security
**Subcategory:** PR.PS-05

**Framework Text:** "Installation and execution of unauthorized software are prevented"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for lack of application whitelisting, missing software restriction policies, absence of code signing enforcement, uncontrolled software installations, failure to prevent unauthorized executables, and inadequate application control mechanisms.
