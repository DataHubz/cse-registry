# CSE-NISTCSF-PS-NO-LOG-GENERATION-004

**Log Records Not Generated**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-PS-NO-LOG-GENERATION-004` |
| Domain          | NISTCSF                                  |
| Category        | Platform Security                        |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Log records are not generated and made available for continuous monitoring.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Data protection and platform security teams
- Infrastructure resilience programs
- Organizations managing technology platforms

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** PR.PS - Platform Security
**Subcategory:** PR.PS-04

**Framework Text:** "Log records are generated and made available for continuous monitoring"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for disabled logging services, incomplete audit trails, insufficient log retention, lack of log aggregation mechanisms, missing security event logging, and failure to make logs accessible for monitoring and analysis.
