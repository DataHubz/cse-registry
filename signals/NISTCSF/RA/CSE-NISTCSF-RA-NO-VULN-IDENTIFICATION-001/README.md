# CSE-NISTCSF-RA-NO-VULN-IDENTIFICATION-001

**No Vulnerability Identification**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-RA-NO-VULN-IDENTIFICATION-001` |
| Domain          | NISTCSF                                  |
| Category        | RA                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Vulnerabilities in assets are not identified, validated, and recorded.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity risk management
- Risk assessment and vulnerability management teams
- Security operations and threat intelligence functions
- Organizations conducting security assessments

## NIST CSF 2.0 Context (Informative)

**Function:** IDENTIFY (ID)
**Category:** ID.RA - Risk Assessment
**Subcategory:** ID.RA-01

**Framework Text:** "Vulnerabilities in assets are identified, validated, and recorded"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: This signal indicates that vulnerability scanning, validation, and documentation processes are not in place or functioning. Organizations should implement vulnerability assessment programs including automated scanning, manual testing, and vulnerability tracking systems.
