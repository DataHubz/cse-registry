# CSE-NISTCSF-RA-NO-THREAT-IDENTIFICATION-003

**No Threat Identification**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-RA-NO-THREAT-IDENTIFICATION-003` |
| Domain          | NISTCSF                                  |
| Category        | RA                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Internal and external threats to the organization are not identified and recorded.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity risk management
- Risk assessment and vulnerability management teams
- Security operations and threat intelligence functions
- Organizations conducting security assessments

## NIST CSF 2.0 Context (Informative)

**Function:** IDENTIFY (ID)
**Category:** ID.RA - Risk Assessment
**Subcategory:** ID.RA-03

**Framework Text:** "Internal and external threats to the organization are identified and recorded"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: This signal indicates that threat identification processes are not established or maintained. Organizations should implement threat modeling, threat intelligence analysis, and threat documentation processes to identify both external threat actors and internal threat scenarios relevant to their environment.
