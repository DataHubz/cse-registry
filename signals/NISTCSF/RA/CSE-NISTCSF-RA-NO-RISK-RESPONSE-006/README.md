# CSE-NISTCSF-RA-NO-RISK-RESPONSE-006

**No Risk Response Management**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-RA-NO-RISK-RESPONSE-006` |
| Domain          | NISTCSF                                  |
| Category        | RA                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Risk responses are not chosen, prioritized, planned, tracked, and communicated.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity risk management
- Risk assessment and vulnerability management teams
- Security operations and threat intelligence functions
- Organizations conducting security assessments

## NIST CSF 2.0 Context (Informative)

**Function:** IDENTIFY (ID)
**Category:** ID.RA - Risk Assessment
**Subcategory:** ID.RA-06

**Framework Text:** "Risk responses are chosen, prioritized, planned, tracked, and communicated"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: This signal indicates that risk treatment processes (accept, mitigate, transfer, avoid) are not documented, tracked, or communicated to stakeholders. Organizations should implement risk response planning, tracking systems, and communication protocols to ensure identified risks are addressed systematically.
