# CSE-NISTCSF-IR-NO-CAPACITY-MGMT-004

**Resource Capacity Not Maintained**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-IR-NO-CAPACITY-MGMT-004` |

| Category        | Technology Infrastructure Resilience     |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Adequate resource capacity to ensure availability is not maintained.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Data protection and platform security teams
- Infrastructure resilience programs
- Organizations managing technology platforms

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** PR.IR - Technology Infrastructure Resilience
**Subcategory:** PR.IR-04

**Framework Text:** "Adequate resource capacity to ensure availability is maintained"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for lack of capacity planning, insufficient resource monitoring, missing scalability mechanisms, inadequate performance baselines, failure to maintain resource reserves, and absence of capacity forecasting processes.
