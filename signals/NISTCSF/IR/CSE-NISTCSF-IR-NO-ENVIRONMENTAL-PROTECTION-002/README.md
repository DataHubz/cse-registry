# CSE-NISTCSF-IR-NO-ENVIRONMENTAL-PROTECTION-002

**Technology Assets Not Protected from Environmental Threats**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-IR-NO-ENVIRONMENTAL-PROTECTION-002` |
| Domain          | NISTCSF                                  |
| Category        | Technology Infrastructure Resilience     |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Technology assets are not protected from environmental threats.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Data protection and platform security teams
- Infrastructure resilience programs
- Organizations managing technology platforms

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** PR.IR - Technology Infrastructure Resilience
**Subcategory:** PR.IR-02

**Framework Text:** "The organization's technology assets are protected from environmental threats"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for lack of physical security controls, inadequate climate control systems, missing fire suppression, absence of power protection (UPS/generators), flood risk mitigation gaps, and insufficient protection against natural disasters and environmental hazards.
