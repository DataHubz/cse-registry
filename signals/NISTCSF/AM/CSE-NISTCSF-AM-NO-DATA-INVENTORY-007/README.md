# CSE-NISTCSF-AM-NO-DATA-INVENTORY-007

**No Data and Metadata Inventory Maintained**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AM-NO-DATA-INVENTORY-007` |
| Domain          | NISTCSF                                  |
| Category        | AM                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Inventories of data and corresponding metadata are not maintained.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity risk management
- IT asset management and inventory teams
- Configuration management programs
- Organizations maintaining technology inventories

## NIST CSF 2.0 Context (Informative)

**Function:** IDENTIFY (ID)
**Category:** ID.AM - Asset Management
**Subcategory:** ID.AM-07

**Framework Text:** "Inventories of data and corresponding metadata for designated data types are maintained"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for absence of data catalogs, missing data classification inventories, lack of metadata management, or gaps in data asset documentation. Organizations should maintain comprehensive inventories that include sensitive data locations, data types, data owners, retention requirements, and processing activities for compliance with privacy and data protection regulations.
