# CSE-NISTCSF-AM-NO-SOFTWARE-INVENTORY-002

**No Software Inventory Maintained**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AM-NO-SOFTWARE-INVENTORY-002` |
| Domain          | NISTCSF                                  |
| Category        | AM                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Inventories of software, services, and systems managed by the organization are not maintained.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity risk management
- IT asset management and inventory teams
- Configuration management programs
- Organizations maintaining technology inventories

## NIST CSF 2.0 Context (Informative)

**Function:** IDENTIFY (ID)
**Category:** ID.AM - Asset Management
**Subcategory:** ID.AM-02

**Framework Text:** "Inventories of software, services, and systems managed by the organization are maintained"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for absence of software inventory management tools, missing application catalogs, lack of license tracking, or gaps in software asset documentation. Organizations should maintain comprehensive inventories that include operating systems, applications, cloud services, SaaS platforms, databases, and middleware components.
