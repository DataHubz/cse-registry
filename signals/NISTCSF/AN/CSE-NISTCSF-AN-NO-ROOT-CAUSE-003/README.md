# CSE-NISTCSF-AN-NO-ROOT-CAUSE-003

**Analysis Not Performed to Establish What Took Place and Root Cause**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AN-NO-ROOT-CAUSE-003` |
| Domain          | NISTCSF                                  |
| Category        | RS.AN                                    |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Analysis is not performed to establish what has taken place and the root cause.

## Applicability

This signal applies to:

- All organizations with incident response capabilities
- Security operations and incident response teams
- Forensics and investigation functions
- Organizations with breach notification requirements

## NIST CSF 2.0 Context (Informative)

**Function:** RESPOND (RS)
**Category:** RS.AN - Incident Analysis
**Subcategory:** RS.AN-03

**Framework Text:** "Analysis is performed to establish what has taken place during an incident and the root cause of the incident"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Identify incidents closed without root cause analysis documentation, missing timeline reconstruction, incomplete attack chain mapping, or incidents lacking determination of initial attack vector. Monitor for cases where remediation occurs without understanding underlying vulnerabilities or configuration weaknesses that enabled the incident.
