# CSE-NISTCSF-RR-NO-PERFORMANCE-ASSESSMENT-004

**Cybersecurity Not Included in Human Resources Practices**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-RR-NO-PERFORMANCE-ASSESSMENT-004` |
| Domain          | NISTCSF                                  |
| Category        | RR                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Cybersecurity is not included in human resources practices.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity risk management
- Enterprise governance and leadership functions
- Strategic planning and risk management teams
- Organizations subject to regulatory compliance requirements

## NIST CSF 2.0 Context (Informative)

**Function:** GOVERN (GV)
**Category:** GV.RR - Roles, Responsibilities, and Authorities
**Subcategory:** GV.RR-04

**Framework Text:** "Cybersecurity is included in human resources practices"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Identify organizations where cybersecurity is not integrated into hiring processes, job descriptions lack cybersecurity responsibilities, performance reviews do not include security metrics, onboarding/offboarding procedures lack security components, or security awareness training is not mandatory for all personnel.
