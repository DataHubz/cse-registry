# CSE-NISTCSF-CM-NO-PHYSICAL-MONITORING-002

**No Physical Environment Monitoring**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-CM-NO-PHYSICAL-MONITORING-002` |
| Domain          | NISTCSF                                  |
| Category        | CM                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

The physical environment is not monitored for potentially adverse events.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity detection capabilities
- Security operations and monitoring teams
- Threat detection and analysis functions
- Organizations with continuous monitoring requirements

## NIST CSF 2.0 Context (Informative)

**Function:** DETECT (DE)
**Category:** DE.CM - Continuous Monitoring
**Subcategory:** DE.CM-02

**Framework Text:** "The physical environment is monitored to find potentially adverse events"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Organizations should implement monitoring of physical facilities, data centers, and other critical areas using surveillance systems, access logs, environmental sensors, and alarm systems to detect unauthorized physical access, environmental hazards, or other potentially adverse physical events that could impact information assets.
