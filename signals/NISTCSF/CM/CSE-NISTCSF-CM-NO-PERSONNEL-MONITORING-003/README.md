# CSE-NISTCSF-CM-NO-PERSONNEL-MONITORING-003

**No Personnel Activity Monitoring**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-CM-NO-PERSONNEL-MONITORING-003` |
| Domain          | NISTCSF                                  |
| Category        | CM                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Personnel activity and technology usage are not monitored for potentially adverse events.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity detection capabilities
- Security operations and monitoring teams
- Threat detection and analysis functions
- Organizations with continuous monitoring requirements

## NIST CSF 2.0 Context (Informative)

**Function:** DETECT (DE)
**Category:** DE.CM - Continuous Monitoring
**Subcategory:** DE.CM-03

**Framework Text:** "Personnel activity and technology usage are monitored to find potentially adverse events"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Organizations should monitor user activities, authentication events, privileged access usage, data access patterns, and technology usage to detect insider threats, compromised accounts, policy violations, or other potentially adverse events. This includes monitoring for anomalous behavior patterns and unauthorized activities while respecting privacy considerations.
