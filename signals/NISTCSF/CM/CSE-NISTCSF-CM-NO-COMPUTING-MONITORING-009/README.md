# CSE-NISTCSF-CM-NO-COMPUTING-MONITORING-009

**No Computing Hardware and Software Monitoring**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-CM-NO-COMPUTING-MONITORING-009` |
| Domain          | NISTCSF                                  |
| Category        | CM                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Computing hardware and software are not monitored for potentially adverse events.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity detection capabilities
- Security operations and monitoring teams
- Threat detection and analysis functions
- Organizations with continuous monitoring requirements

## NIST CSF 2.0 Context (Informative)

**Function:** DETECT (DE)
**Category:** DE.CM - Continuous Monitoring
**Subcategory:** DE.CM-09

**Framework Text:** "Computing hardware and software, runtime environments, and their data are monitored to find potentially adverse events"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Organizations should monitor endpoints, servers, workstations, mobile devices, containers, virtual machines, and their associated software and runtime environments. This includes monitoring for malware, unauthorized changes, configuration drift, vulnerability exploitation, resource consumption anomalies, and data integrity issues that could indicate potentially adverse events.
