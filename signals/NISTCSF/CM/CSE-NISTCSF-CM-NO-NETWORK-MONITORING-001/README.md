# CSE-NISTCSF-CM-NO-NETWORK-MONITORING-001

**No Network Monitoring**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-CM-NO-NETWORK-MONITORING-001` |
| Domain          | NISTCSF                                  |
| Category        | CM                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Networks and network services are not monitored for potentially adverse events.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity detection capabilities
- Security operations and monitoring teams
- Threat detection and analysis functions
- Organizations with continuous monitoring requirements

## NIST CSF 2.0 Context (Informative)

**Function:** DETECT (DE)
**Category:** DE.CM - Continuous Monitoring
**Subcategory:** DE.CM-01

**Framework Text:** "Networks and network services are monitored to find potentially adverse events"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Organizations should implement continuous monitoring of network traffic, network services (DNS, DHCP, etc.), and network infrastructure to detect anomalies, unauthorized access attempts, malicious traffic patterns, and other potentially adverse events. This includes monitoring both internal and external network boundaries.
