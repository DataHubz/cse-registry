# CSE-NISTCSF-AE-NO-INFO-SHARING-006

**No Information Sharing on Adverse Events**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AE-NO-INFO-SHARING-006` |
| Domain          | NISTCSF                                  |
| Category        | AE                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Information on adverse events is not provided to authorized staff and tools.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity detection capabilities
- Security operations and monitoring teams
- Threat detection and analysis functions
- Organizations with continuous monitoring requirements

## NIST CSF 2.0 Context (Informative)

**Function:** DETECT (DE)
**Category:** DE.AE - Adverse Event Analysis
**Subcategory:** DE.AE-06

**Framework Text:** "Information on adverse events is provided to authorized staff and tools"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Organizations should establish processes to share relevant information about adverse events with appropriate internal stakeholders (security teams, incident responders, management) and automated security tools (SIEM, SOAR, threat intelligence platforms). This sharing should follow established authorization protocols and enable coordinated detection and response activities.
