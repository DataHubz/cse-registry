# CSE-NISTCSF-AE-NO-INCIDENT-DECLARATION-008

**No Incident Declaration Process**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AE-NO-INCIDENT-DECLARATION-008` |
| Domain          | NISTCSF                                  |
| Category        | AE                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Incidents are not declared when adverse events meet defined criteria.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity detection capabilities
- Security operations and monitoring teams
- Threat detection and analysis functions
- Organizations with continuous monitoring requirements

## NIST CSF 2.0 Context (Informative)

**Function:** DETECT (DE)
**Category:** DE.AE - Adverse Event Analysis
**Subcategory:** DE.AE-08

**Framework Text:** "Incidents are declared when adverse events meet the defined incident criteria"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Organizations should establish clear criteria for when adverse events are escalated to formal incident status and implement processes to ensure timely incident declaration. This includes defining severity thresholds, impact criteria, and authorization procedures that trigger the transition from event detection to incident response activities.
