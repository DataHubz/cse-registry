# CSE-NISTCSF-AE-NO-IMPACT-SCOPE-004

**No Impact and Scope Understanding**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AE-NO-IMPACT-SCOPE-004` |
| Domain          | NISTCSF                                  |
| Category        | AE                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

The estimated impact and scope of adverse events are not understood.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity detection capabilities
- Security operations and monitoring teams
- Threat detection and analysis functions
- Organizations with continuous monitoring requirements

## NIST CSF 2.0 Context (Informative)

**Function:** DETECT (DE)
**Category:** DE.AE - Adverse Event Analysis
**Subcategory:** DE.AE-04

**Framework Text:** "The estimated impact and scope of adverse events are understood"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Organizations should assess and document the estimated impact of adverse events on business operations, data confidentiality, system integrity, and service availability. Understanding the scope includes identifying all affected systems, users, data assets, and business processes to enable appropriate prioritization and response actions.
