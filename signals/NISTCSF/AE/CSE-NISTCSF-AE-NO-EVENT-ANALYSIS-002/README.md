# CSE-NISTCSF-AE-NO-EVENT-ANALYSIS-002

**No Adverse Event Analysis**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AE-NO-EVENT-ANALYSIS-002` |
| Domain          | NISTCSF                                  |
| Category        | AE                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Potentially adverse events are not analyzed to understand associated activities.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity detection capabilities
- Security operations and monitoring teams
- Threat detection and analysis functions
- Organizations with continuous monitoring requirements

## NIST CSF 2.0 Context (Informative)

**Function:** DETECT (DE)
**Category:** DE.AE - Adverse Event Analysis
**Subcategory:** DE.AE-02

**Framework Text:** "Potentially adverse events are analyzed to better understand associated activities"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Organizations should perform detailed analysis of detected potentially adverse events to understand the full scope of related activities, attack patterns, affected systems, timelines, and potential indicators of compromise. This analysis helps distinguish true security incidents from false positives and enables effective response planning.
