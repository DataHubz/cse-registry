# CSE-NISTCSF-AE-NO-INFO-CORRELATION-003

**No Information Correlation**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AE-NO-INFO-CORRELATION-003` |
| Domain          | NISTCSF                                  |
| Category        | AE                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Information from multiple sources is not correlated.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity detection capabilities
- Security operations and monitoring teams
- Threat detection and analysis functions
- Organizations with continuous monitoring requirements

## NIST CSF 2.0 Context (Informative)

**Function:** DETECT (DE)
**Category:** DE.AE - Adverse Event Analysis
**Subcategory:** DE.AE-03

**Framework Text:** "Information is correlated from multiple sources"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Organizations should correlate security events, alerts, and data from multiple sources such as network monitoring tools, endpoint detection systems, authentication logs, threat intelligence feeds, and physical security systems. This correlation enables detection of complex, multi-stage attacks and provides comprehensive visibility into potential security incidents.
