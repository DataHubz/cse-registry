# CSE-NISTCSF-AT-NO-SPECIALIZED-TRAINING-002

**No Specialized Role Training**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-AT-NO-SPECIALIZED-TRAINING-002` |
| Domain          | NISTCSF                                  |
| Category        | AT                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Individuals in specialized roles are not provided with awareness and training.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Identity and access management teams
- Security awareness and training programs
- Organizations managing user authentication

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** Awareness and Training
**Subcategory:** PR.AT-02

**Framework Text:** "Individuals in specialized roles are provided with awareness and training so that they possess the knowledge and skills to perform relevant tasks with cybersecurity risks in mind"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Identify gaps in role-specific security training for personnel with specialized responsibilities, including system administrators, developers, security operations staff, privacy officers, and other roles requiring advanced security knowledge, where targeted training programs on role-specific threats, secure practices, and compliance requirements are missing or inadequate.
