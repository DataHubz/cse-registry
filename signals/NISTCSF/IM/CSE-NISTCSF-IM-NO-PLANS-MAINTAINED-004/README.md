# CSE-NISTCSF-IM-NO-PLANS-MAINTAINED-004

**Incident Response Plans and Cybersecurity Plans Not Maintained**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-IM-NO-PLANS-MAINTAINED-004` |
| Domain          | NISTCSF                                  |
| Category        | IM                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Incident response plans and other cybersecurity plans are not established and maintained.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity risk management
- Continuous improvement and process optimization teams
- Security testing and assessment functions
- Organizations conducting lessons learned activities

## NIST CSF 2.0 Context (Informative)

**Function:** IDENTIFY (ID)
**Category:** ID.IM - Improvement
**Subcategory:** ID.IM-04

**Framework Text:** "Incident response plans and other cybersecurity plans that affect operations are established, communicated, maintained, and improved"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for outdated or non-existent incident response plans, lack of plan distribution to relevant stakeholders, missing regular plan reviews and updates, or absence of plan testing and improvement cycles based on lessons learned.
