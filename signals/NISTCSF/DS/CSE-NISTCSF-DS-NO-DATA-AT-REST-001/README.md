# CSE-NISTCSF-DS-NO-DATA-AT-REST-001

**Data at Rest Not Protected**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-DS-NO-DATA-AT-REST-001` |
| Domain          | NISTCSF                                  |
| Category        | Data Security                            |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

The confidentiality, integrity, and availability of data-at-rest are not protected.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Data protection and platform security teams
- Infrastructure resilience programs
- Organizations managing technology platforms

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** PR.DS - Data Security
**Subcategory:** PR.DS-01

**Framework Text:** "The confidentiality, integrity, and availability of data-at-rest are protected"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for unencrypted data storage, missing encryption controls, inadequate access controls on stored data, lack of integrity verification mechanisms, and insufficient availability protections for data at rest.
