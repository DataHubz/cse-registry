# CSE-NISTCSF-DS-NO-BACKUP-PROTECTION-011

**Backups Not Protected**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-NISTCSF-DS-NO-BACKUP-PROTECTION-011` |
| Domain          | NISTCSF                                  |
| Category        | Data Security                            |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Backups of data are not created, protected, maintained, and tested.

## Applicability

This signal applies to:

- All organizations implementing cybersecurity safeguards
- Data protection and platform security teams
- Infrastructure resilience programs
- Organizations managing technology platforms

## NIST CSF 2.0 Context (Informative)

**Function:** PROTECT (PR)
**Category:** PR.DS - Data Security
**Subcategory:** PR.DS-11

**Framework Text:** "Backups of data are created, protected, maintained, and tested"

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for missing backup schedules, unencrypted backups, lack of backup testing procedures, inadequate backup retention policies, failure to verify backup integrity, and absence of secure backup storage locations.
