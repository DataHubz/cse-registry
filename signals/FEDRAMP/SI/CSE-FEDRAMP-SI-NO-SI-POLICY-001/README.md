# CSE-FEDRAMP-SI-NO-SI-POLICY-001

**No System and Information Integrity Policy**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-FEDRAMP-SI-NO-SI-POLICY-001`       |
| Domain          | FEDRAMP                                  |
| Category        | SI                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

System and information integrity policy and procedures are not established.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** System and Information Integrity (SI)
**Control:** SI-1
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Develop, document, and disseminate a system and information integrity policy... and procedures."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing system and information integrity policy documentation, absence of flaw remediation procedures, malicious code protection procedures, and monitoring procedures.
