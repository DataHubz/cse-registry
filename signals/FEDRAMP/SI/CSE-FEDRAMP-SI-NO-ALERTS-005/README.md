# CSE-FEDRAMP-SI-NO-ALERTS-005

**No Security Alerts and Advisories**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-FEDRAMP-SI-NO-ALERTS-005`          |
| Domain          | FEDRAMP                                  |
| Category        | SI                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Security alerts, advisories, and directives are not received, tracked, or disseminated on an ongoing basis.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** System and Information Integrity (SI)
**Control:** SI-5
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Receive system security alerts, advisories, and directives from designated sources on an ongoing basis; generate internal alerts and advisories; and disseminate to appropriate personnel."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing processes to receive security alerts from sources like US-CERT, vendor security bulletins, absence of internal alert distribution mechanisms, and lack of documented response procedures to security advisories.
