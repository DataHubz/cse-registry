# CSE-FEDRAMP-SA-NO-DOCUMENTATION-005

**No System Documentation**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-FEDRAMP-SA-NO-DOCUMENTATION-005` |
| Domain          | FEDRAMP                                  |
| Category        | SA                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Administrator, user, and developer documentation for the information system is not obtained, protected, or distributed as required.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** System and Services Acquisition (SA)
**Control:** SA-5
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Obtain or develop administrator documentation for the system, system component, or system service that describes: (1) Secure configuration, installation, and operation of the system, component, or service; (2) Effective use and maintenance of security and privacy functions and mechanisms; and (3) Known vulnerabilities regarding configuration and use of administrative or privileged functions; Obtain or develop user documentation for the system, system component, or system service that describes: (1) User-accessible security and privacy functions and mechanisms and how to effectively use those functions and mechanisms; (2) Methods for user interaction, which enables individuals to use the system, component, or service in a more secure manner and protect individual privacy; and (3) User responsibilities in maintaining the security of the system, component, or service and privacy of individuals; and Document attempts to obtain system, system component, or system service documentation when such documentation is either unavailable or nonexistent and take [Assignment: organization-defined actions] in response."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing administrator documentation, absent user guides, lack of developer documentation, inadequate security configuration guides, missing privacy function descriptions, incomplete operational procedures, unprotected documentation, and absence of distribution controls for sensitive documentation.
