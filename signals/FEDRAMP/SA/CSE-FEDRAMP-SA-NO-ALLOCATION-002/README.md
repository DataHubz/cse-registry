# CSE-FEDRAMP-SA-NO-ALLOCATION-002

**No Allocation of Resources**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-FEDRAMP-SA-NO-ALLOCATION-002` |
| Domain          | FEDRAMP                                  |
| Category        | SA                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Resources required for information security and privacy protection are not determined, documented, and allocated as part of organizational capital planning and investment control processes.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** System and Services Acquisition (SA)
**Control:** SA-2
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Determine, document, and allocate the resources required to protect the system as part of the organizational capital planning and investment control process; and establish a discrete line item for information security and privacy in organizational programming and budgeting documentation."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing resource allocation documentation, absence of security and privacy budget line items, lack of capital planning integration for security requirements, missing cost estimates for security controls, and inadequate funding for security and privacy protection activities.
