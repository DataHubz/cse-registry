# CSE-FEDRAMP-IR-NO-INCIDENT-REPORTING-006

**No Incident Reporting**

## Signal Overview

| Field           | Value                                       |
|-----------------|---------------------------------------------|
| Identifier      | `CSE-FEDRAMP-IR-NO-INCIDENT-REPORTING-006` |
| Domain          | FEDRAMP                                     |
| Category        | IR                                          |
| Status          | Active                                      |
| Introduced In   | 1.0.0                                       |

## Description

Incident reporting mechanisms are not established to require personnel to report suspected security incidents to appropriate organizational authorities.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Incident Response (IR)
**Control:** IR-6
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Require personnel to report suspected incidents to the organizational incident response capability within an organization-defined time period."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing incident reporting procedures, absence of reporting timelines, lack of defined reporting channels, and missing documentation on incident escalation paths.
