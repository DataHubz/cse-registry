# CSE-FEDRAMP-IR-NO-INCIDENT-MONITORING-005

**No Incident Monitoring**

## Signal Overview

| Field           | Value                                       |
|-----------------|---------------------------------------------|
| Identifier      | `CSE-FEDRAMP-IR-NO-INCIDENT-MONITORING-005`|
| Domain          | FEDRAMP                                     |
| Category        | IR                                          |
| Status          | Active                                      |
| Introduced In   | 1.0.0                                       |

## Description

Incident monitoring capabilities are not implemented to track and document system security incidents.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Incident Response (IR)
**Control:** IR-5
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Track and document incidents."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing incident tracking systems, absence of incident documentation, and lack of incident management tools or databases.
