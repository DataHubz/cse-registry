# CSE-FEDRAMP-IR-NO-INCIDENT-HANDLING-004

**No Incident Handling**

## Signal Overview

| Field           | Value                                       |
|-----------------|---------------------------------------------|
| Identifier      | `CSE-FEDRAMP-IR-NO-INCIDENT-HANDLING-004`  |
| Domain          | FEDRAMP                                     |
| Category        | IR                                          |
| Status          | Active                                      |
| Introduced In   | 1.0.0                                       |

## Description

Incident handling capability is not implemented for preparation, detection and analysis, containment, eradication, and recovery.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Incident Response (IR)
**Control:** IR-4
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Implement an incident handling capability for incidents that includes preparation, detection and analysis, containment, eradication, and recovery."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing incident handling procedures, absence of incident detection mechanisms, lack of containment and eradication processes, and missing recovery procedures.
