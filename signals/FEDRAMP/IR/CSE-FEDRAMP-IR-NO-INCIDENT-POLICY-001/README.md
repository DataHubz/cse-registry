# CSE-FEDRAMP-IR-NO-INCIDENT-POLICY-001

**No Incident Response Policy**

## Signal Overview

| Field           | Value                                       |
|-----------------|---------------------------------------------|
| Identifier      | `CSE-FEDRAMP-IR-NO-INCIDENT-POLICY-001`    |
| Domain          | FEDRAMP                                     |
| Category        | IR                                          |
| Status          | Active                                      |
| Introduced In   | 1.0.0                                       |

## Description

Incident response policy and procedures are not established.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Incident Response (IR)
**Control:** IR-1
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Develop, document, and disseminate an incident response policy... and procedures."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing incident response policy documentation, absence of incident handling procedures, and lack of defined incident response roles and responsibilities.
