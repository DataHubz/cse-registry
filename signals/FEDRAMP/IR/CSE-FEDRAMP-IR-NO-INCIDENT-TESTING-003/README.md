# CSE-FEDRAMP-IR-NO-INCIDENT-TESTING-003

**No Incident Response Testing**

## Signal Overview

| Field           | Value                                       |
|-----------------|---------------------------------------------|
| Identifier      | `CSE-FEDRAMP-IR-NO-INCIDENT-TESTING-003`   |
| Domain          | FEDRAMP                                     |
| Category        | IR                                          |
| Status          | Active                                      |
| Introduced In   | 1.0.0                                       |

## Description

Incident response capabilities are not tested through simulations, exercises, or testing procedures.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Incident Response (IR)
**Control:** IR-3
**Baseline:** Moderate, High

**NIST 800-53 Text:** "Test the effectiveness of the incident response capability using tests and/or exercises."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing incident response testing documentation, absence of tabletop exercises or simulations, and lack of testing schedules or after-action reports.
