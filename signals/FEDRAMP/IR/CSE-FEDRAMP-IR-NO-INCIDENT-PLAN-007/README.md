# CSE-FEDRAMP-IR-NO-INCIDENT-PLAN-007

**No Incident Response Plan**

## Signal Overview

| Field           | Value                                       |
|-----------------|---------------------------------------------|
| Identifier      | `CSE-FEDRAMP-IR-NO-INCIDENT-PLAN-007`      |
| Domain          | FEDRAMP                                     |
| Category        | IR                                          |
| Status          | Active                                      |
| Introduced In   | 1.0.0                                       |

## Description

Incident response plan is not developed, documented, and implemented to provide an organized approach to responding to security incidents.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Incident Response (IR)
**Control:** IR-8
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Develop an incident response plan that provides the organization with a roadmap for implementing its incident response capability."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing incident response plan documentation, absence of response procedures and workflows, lack of defined roles and responsibilities, and missing communication plans for incident response.
