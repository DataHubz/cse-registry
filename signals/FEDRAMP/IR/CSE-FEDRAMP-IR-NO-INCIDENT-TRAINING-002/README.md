# CSE-FEDRAMP-IR-NO-INCIDENT-TRAINING-002

**No Incident Response Training**

## Signal Overview

| Field           | Value                                       |
|-----------------|---------------------------------------------|
| Identifier      | `CSE-FEDRAMP-IR-NO-INCIDENT-TRAINING-002`  |
| Domain          | FEDRAMP                                     |
| Category        | IR                                          |
| Status          | Active                                      |
| Introduced In   | 1.0.0                                       |

## Description

Incident response training is not provided to users with assigned incident response roles and responsibilities.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Incident Response (IR)
**Control:** IR-2
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Provide incident response training to system users consistent with assigned roles and responsibilities."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing incident response training programs, absence of training records for incident response personnel, and lack of role-based training documentation.
