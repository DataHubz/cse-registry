# CSE-FEDRAMP-PE-NO-ACCESS-MONITORING-004

**No Physical Access Monitoring**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-FEDRAMP-PE-NO-ACCESS-MONITORING-004` |
| Domain          | FEDRAMP                                  |
| Category        | PE                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Physical access to facilities is not monitored to detect and respond to physical security incidents.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Physical and Environmental Protection (PE)
**Control:** PE-6
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Monitor physical access to the facility where the system resides to detect and respond to physical security incidents; review physical access logs; and coordinate results of reviews and investigations with the organizational incident response capability."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing video surveillance systems, lack of physical access logs, absence of intrusion detection systems, inadequate review of physical access events, missing coordination with incident response, and no evidence of monitoring for physical security incidents.
