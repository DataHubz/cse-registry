# CSE-FEDRAMP-CM-NO-SW-USAGE-009

**No Software Usage Restrictions**

## Signal Overview

| Field           | Value                                   |
|-----------------|-----------------------------------------|
| Identifier      | `CSE-FEDRAMP-CM-NO-SW-USAGE-009`       |
| Domain          | FEDRAMP                                 |
| Category        | CM                                      |
| Status          | Active                                  |
| Introduced In   | 1.0.0                                   |

## Description

No restrictions have been established and enforced on the use of software to ensure compliance with contract agreements and copyright laws.

## Applicability

This signal applies to:

- Cloud Service Providers (CSPs) seeking FedRAMP authorization
- Federal agencies operating cloud systems
- Third Party Assessment Organizations (3PAOs) conducting assessments
- Federal information systems processing government data

## FedRAMP Context (Informative)

**Control Family:** Configuration Management (CM)
**Control Number:** CM-10
**FedRAMP Baseline:** Low, Moderate, High

**NIST SP 800-53 Rev. 5 Text:** "The organization establishes [Assignment: organization-defined software and information usage restrictions]; and establishes controls to enforce software and information usage restrictions."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review software asset management systems, license management databases, and acceptable use policies to verify controls on software usage. Look for absence of software whitelisting or blacklisting, missing license compliance tracking, unauthorized software installations, or lack of software usage policies. Check for systems lacking controls to prevent unlicensed software installation, missing software approval processes, or absence of periodic software audits to ensure license compliance and identify unauthorized applications.
