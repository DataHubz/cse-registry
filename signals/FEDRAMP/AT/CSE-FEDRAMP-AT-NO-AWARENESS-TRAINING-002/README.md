# CSE-FEDRAMP-AT-NO-AWARENESS-TRAINING-002

**No Security Awareness Training**

## Signal Overview

| Field           | Value                                       |
|-----------------|---------------------------------------------|
| Identifier      | `CSE-FEDRAMP-AT-NO-AWARENESS-TRAINING-002` |
| Domain          | FEDRAMP                                     |
| Category        | AT                                          |
| Status          | Active                                      |
| Introduced In   | 1.0.0                                       |

## Description

Personnel do not receive security and privacy awareness training upon initial assignment and at least annually thereafter.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Awareness and Training (AT)
**Control:** AT-2
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Provide security and privacy literacy training to system users (including managers, senior executives, and contractors)... as part of initial training for new users and at least annually thereafter."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing training completion records, lack of training scheduling, absence of annual refresher training, and no evidence of initial onboarding security training.
