# CSE-FEDRAMP-MA-NO-MAINTENANCE-POLICY-001

**No System Maintenance Policy**

## Signal Overview

| Field           | Value                                         |
|-----------------|-----------------------------------------------|
| Identifier      | `CSE-FEDRAMP-MA-NO-MAINTENANCE-POLICY-001`   |
| Domain          | FEDRAMP                                       |
| Category        | MA                                            |
| Status          | Active                                        |
| Introduced In   | 1.0.0                                         |

## Description

System maintenance policy and procedures are not established, documented, or disseminated.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Maintenance (MA)
**Control:** MA-1
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Develop, document, and disseminate a system maintenance policy and procedures for system maintenance."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing maintenance policy documentation, absence of maintenance procedures, lack of defined maintenance schedules, and no documented maintenance roles and responsibilities.
