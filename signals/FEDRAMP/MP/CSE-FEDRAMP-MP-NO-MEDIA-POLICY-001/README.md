# CSE-FEDRAMP-MP-NO-MEDIA-POLICY-001

**No Media Protection Policy**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-FEDRAMP-MP-NO-MEDIA-POLICY-001` |
| Domain          | FEDRAMP                                  |
| Category        | MP                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Media protection policy and procedures are not developed, documented, and maintained.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Media Protection (MP)
**Control:** MP-1
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Develop, document, and disseminate a media protection policy... and procedures to facilitate the implementation of the media protection policy and the associated media protection controls."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing media protection policy documentation, outdated procedures, lack of policy dissemination evidence, absence of defined roles and responsibilities for media protection, and missing guidelines for media handling, storage, transport, and sanitization.
