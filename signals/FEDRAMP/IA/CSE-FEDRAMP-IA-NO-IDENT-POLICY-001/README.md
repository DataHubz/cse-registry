# CSE-FEDRAMP-IA-NO-IDENT-POLICY-001

**No Identification and Authentication Policy**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-FEDRAMP-IA-NO-IDENT-POLICY-001` |
| Domain          | FEDRAMP                                  |
| Category        | IA                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Identification and authentication policy and procedures are not developed, documented, and maintained.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Identification and Authentication (IA)
**Control:** IA-1
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Develop, document, and disseminate an identification and authentication policy... and procedures to facilitate the implementation of the identification and authentication policy and the associated identification and authentication controls."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing identification and authentication policy documentation, outdated procedures, lack of policy dissemination evidence, absence of defined roles and responsibilities for managing user identities and authentication mechanisms, and missing policy review and update schedules.
