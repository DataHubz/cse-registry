# CSE-FEDRAMP-AC-NO-ACCESS-POLICY-001

**No Access Control Policy**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-FEDRAMP-AC-NO-ACCESS-POLICY-001` |
| Domain          | FEDRAMP                                  |
| Category        | AC                                       |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

Access control policy and procedures are not developed, documented, and maintained.

## Applicability

This signal applies to:

- Cloud Service Providers seeking FedRAMP authorization
- Federal agencies using cloud services
- Third-party assessment organizations (3PAOs)
- Systems processing federal information

## FedRAMP Context (Informative)

**Control Family:** Access Control (AC)
**Control:** AC-1
**Baseline:** Low, Moderate, High

**NIST 800-53 Text:** "Develop, document, and disseminate an access control policy... and procedures to facilitate the implementation of the access control policy and the associated access controls."

This reference is informative and does not constitute compliance guidance.

## Notes

Detection guidance: Look for missing access control policy documentation, outdated procedures, lack of policy dissemination evidence, and absence of defined roles and responsibilities for access control.
