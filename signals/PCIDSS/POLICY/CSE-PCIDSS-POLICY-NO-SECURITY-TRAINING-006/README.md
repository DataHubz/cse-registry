# CSE-PCIDSS-POLICY-NO-SECURITY-TRAINING-006

**No Security Awareness Training**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-PCIDSS-POLICY-NO-SECURITY-TRAINING-006` |
| Domain          | PCIDSS                                   |
| Category        | POLICY                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No annual security awareness training for employees.

## Applicability

This signal applies to:

- Organizations processing, storing, or transmitting cardholder data
- Security and compliance teams
- Human resources and training departments
- Third-party service providers (TPSPs)
- Incident response teams

## PCI DSS Context (Informative)

**Requirement:** 12.6 - Security awareness education is an ongoing activity

**Sub-Requirement:** 12.6.1, 12.6.2

**Regulatory Text:** "A formal security awareness program is implemented to make all personnel aware of the entity's information security policy and procedures, and personnel's role in protecting the cardholder data. Personnel receive security awareness training as follows: Upon hire and at least once every 12 months."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Monitor for absence of documented security awareness program, training materials, attendance records, and acknowledgment forms. Verify annual training completion for all personnel with access to cardholder data or the CDE. Check for training content covering security policies, acceptable use, and incident reporting.
