# CSE-PCIDSS-ACCESS-NO-ACCESS-PROCESS-001

**No Access Restriction Processes**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-PCIDSS-ACCESS-NO-ACCESS-PROCESS-001` |
| Domain          | PCIDSS                                   |
| Category        | ACCESS                                   |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No defined processes for restricting access based on business need to know.

## Applicability

This signal applies to:

- Organizations processing, storing, or transmitting cardholder data
- Identity and access management systems
- User directories and authentication services
- Administrative access to CDE components
- Remote access to payment systems

## PCI DSS Context (Informative)

**Requirement:** 7.1 Processes and mechanisms for restricting access to system components and cardholder data by business need to know are defined and understood.

**Sub-Requirement:** 7.1.1

**Regulatory Text:** "Processes and mechanisms for restricting access to system components and cardholder data by business need to know are defined, documented, implemented, and followed."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review organizational policies and procedures for evidence of documented access restriction processes. Look for formal access request and approval workflows, documented business justification requirements, and periodic access reviews. Absence of these documented processes indicates this signal.
