# CSE-PCIDSS-NET-NO-NSC-PROCESS-001

**No Network Security Control Processes**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-PCIDSS-NET-NO-NSC-PROCESS-001` |
| Domain          | PCIDSS                                   |
| Category        | NET                                      |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No defined processes for maintaining network security controls.

## Applicability

This signal applies to:

- Organizations processing, storing, or transmitting cardholder data
- Payment processors and service providers
- E-commerce platforms and merchants
- Point-of-sale (POS) systems
- Network infrastructure within CDE scope

## PCI DSS Context (Informative)

**Requirement:** 1.1 Processes and mechanisms for installing and maintaining network security controls are defined and understood.
**Sub-Requirement:** 1.1.1

**Regulatory Text:** "All security policies and operational procedures that are identified in Requirement 1 are documented, kept up to date, in use, and known to all affected parties."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Look for missing or outdated network security policies, lack of documented procedures for firewall rule management, absence of network diagrams showing CDE boundaries, and missing processes for reviewing and approving network configuration changes.
