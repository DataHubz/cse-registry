# CSE-GDPR-PRINCIPLES-NO-ACCOUNTABILITY-009

**Accountability Not Demonstrated**

## Signal Overview

| Field | Value |
|-------|-------|
| Identifier | `CSE-GDPR-PRINCIPLES-NO-ACCOUNTABILITY-009` |
| Domain | GDPR |
| Category | PRINCIPLES |
| Status | Active |
| Introduced In | 1.0.0 |

## Description

The controller cannot demonstrate compliance with GDPR data protection principles.

Accountability requires documented evidence of compliance measures and their effectiveness.

## Applicability

- Data protection policies and procedures
- Records of processing activities
- Training and awareness programs
- Impact assessments documentation
- Audit trails and compliance evidence

## Examples (Non-Normative)

### Missing Documentation

```yaml
accountability:
  data_protection_policy: null
  processing_records: null
  training_records: null
  dpia_documentation: null
```

### Unverifiable Compliance

```
Compliance Evidence:
  Written Policies: None
  Staff Training: Undocumented
  Processing Records: Incomplete
  Audit History: None
```

## GDPR Context (Informative)

- **Art. 5.2**: The controller shall be responsible for, and be able to demonstrate compliance with, paragraph 1 ('accountability')
