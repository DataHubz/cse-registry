# CSE-HITRUST-PHYSICAL-NO-DISPOSAL-008

**Secure Disposal Missing**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HITRUST-PHYSICAL-NO-DISPOSAL-008` |
| Domain          | HITRUST                                  |
| Category        | PHYSICAL                                 |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No secure disposal procedures in place for equipment, media, or documents containing sensitive information to prevent unauthorized disclosure.

## Applicability

This signal applies to:

- Storage media (hard drives, SSDs, tapes)
- Paper documents and printouts
- Decommissioned equipment
- Backup media and archives
- Mobile devices and removable media

## HITRUST Context (Informative)

**Control Domain:** 08 - Physical and Environmental Security

**Reference:** 08.h

**Regulatory Text:** "Items of equipment containing storage media shall be verified to ensure that any sensitive data and licensed software has been removed or securely overwritten prior to disposal or re-use."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review disposal procedures for equipment and media including data sanitization methods, certificate of destruction requirements, and approved disposal vendors. Verify that procedures address different types of media and equipment, specify appropriate sanitization techniques (physical destruction, cryptographic erasure, overwriting), and include documentation requirements. Check for controls ensuring that disposal activities are performed by authorized personnel or vendors and that disposal is properly logged and verified.
