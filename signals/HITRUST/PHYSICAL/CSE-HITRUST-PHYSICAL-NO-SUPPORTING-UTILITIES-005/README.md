# CSE-HITRUST-PHYSICAL-NO-SUPPORTING-UTILITIES-005

**Supporting Utilities Not Protected**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HITRUST-PHYSICAL-NO-SUPPORTING-UTILITIES-005` |
| Domain          | HITRUST                                  |
| Category        | PHYSICAL                                 |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No protection in place for supporting utilities that enable information processing facilities including power, cooling, and telecommunications.

## Applicability

This signal applies to:

- Data center power systems and UPS
- HVAC and cooling systems
- Telecommunications infrastructure
- Emergency power generators
- Utility rooms and closets

## HITRUST Context (Informative)

**Control Domain:** 08 - Physical and Environmental Security

**Reference:** 08.e

**Regulatory Text:** "Equipment shall be protected from power failures and other disruptions caused by failures in supporting utilities."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review protection measures for supporting utilities including uninterruptible power supplies (UPS), backup generators, redundant cooling systems, and telecommunications redundancy. Verify that critical systems have adequate protection against utility failures. Check for monitoring systems that alert on utility failures or degradation, and documented procedures for responding to utility interruptions.
