# CSE-HITRUST-PHYSICAL-NO-SECURE-AREAS-003

**Secure Area Procedures Missing**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HITRUST-PHYSICAL-NO-SECURE-AREAS-003` |
| Domain          | HITRUST                                  |
| Category        | PHYSICAL                                 |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No security procedures and controls for working in secure areas to prevent unauthorized access and protect information.

## Applicability

This signal applies to:

- Data centers and server rooms
- Secure offices and work areas
- Information processing facilities
- Areas with sensitive information access
- Restricted zones requiring special authorization

## HITRUST Context (Informative)

**Control Domain:** 08 - Physical and Environmental Security

**Reference:** 08.c

**Regulatory Text:** "Security procedures and controls for working in secure areas shall be designed and implemented."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review documented procedures for working in secure areas including sign-in/sign-out requirements, escort procedures for visitors, prohibition of unauthorized photography or recording, restrictions on food and drink, and requirements for unattended areas. Verify that procedures address both physical security and information protection while personnel are working in secure areas.
