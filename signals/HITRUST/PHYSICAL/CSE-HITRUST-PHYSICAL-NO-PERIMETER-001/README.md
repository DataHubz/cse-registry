# CSE-HITRUST-PHYSICAL-NO-PERIMETER-001

**Physical Security Perimeter Missing**

## Signal Overview

| Field           | Value                                    |
|-----------------|------------------------------------------|
| Identifier      | `CSE-HITRUST-PHYSICAL-NO-PERIMETER-001` |
| Domain          | HITRUST                                  |
| Category        | PHYSICAL                                 |
| Status          | Active                                   |
| Introduced In   | 1.0.0                                    |

## Description

No physical security perimeters defined to protect areas containing sensitive information and information processing facilities.

## Applicability

This signal applies to:

- Data centers and server rooms
- Office facilities with sensitive information
- Areas housing information processing equipment
- Storage areas containing sensitive media
- Facilities with access to covered information

## HITRUST Context (Informative)

**Control Domain:** 08 - Physical and Environmental Security

**Reference:** 08.a

**Regulatory Text:** "Security perimeters shall be defined and used to protect areas that contain either sensitive or critical information and information processing facilities."

These references are informative and do not constitute compliance guidance.

## Notes

Detection guidance: Review facility security documentation for defined physical security perimeters. Verify that areas containing sensitive information processing systems have clearly defined physical boundaries with appropriate security controls. Check for documented perimeter definitions including walls, card-controlled entry points, and manned reception desks where appropriate.
